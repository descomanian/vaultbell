# Security Policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please **do not** open a public issue. Use GitHub's private vulnerability reporting
(Security tab → "Report a vulnerability") on this repository.

You can expect a first reply within 7 days. Relevant areas include: access outside the chosen vault folder,
unintended writes to notes, exported components, and anything that would contradict the no-network promise.
